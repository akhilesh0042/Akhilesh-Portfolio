# Akhilesh — Modern Full-Stack Portfolio

A sleek, responsive, and interactive personal portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. Designed to showcase full-stack Python & Django engineering projects, technical skills, resume highlights, and live project demos.

---

## ✨ Features

- **🎨 Modern Dark/Light Design System**: Tailored color palette, glassmorphism cards, and smooth micro-animations.
- **🚀 Project Showcase**: Featured interactive cards for full-stack applications (LeavEase, ALAMARAi, Django REST API Core, CampusConnect) with detailed modal views, key highlights, and technology tags.
- **🛠️ Interactive Skill Matrix**: Categorized tech stacks spanning Languages, Frameworks & Backend, Databases, and Developer Tools.
- **📄 Live Resume Modal**: Embedded resume summary, education, experience, and certifications with instant download/view capabilities.
- **⚡ Supercharged by Vite & React 19**: Ultra-fast build times, HMR, and smooth component rendering.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Tooling**: PostCSS, Autoprefixer, Oxlint
- **Backend Projects Highlighted**: Python, Django, Django REST Framework, MySQL, Google Gemini API

## 🚀 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   cd "Akhilesh Portfolio"
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

4. **Build for production:**

   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
